# 新手指南：第一次使用 n8n

*前提：已依照[[同事連線指南 - Windows 連上 n8n]]完成連線，並能開啟 n8n 介面。*

---

## n8n 是什麼？

n8n 是一個**流程自動化工具**，讓你用「拖拉積木」的方式設計自動化流程，不需要從頭寫程式。

舉例：「每天早上 9 點，自動從系統撈資料 → 整理成 Excel → 寄 Email 通知主管」，這整串流程就是一個 **workflow（工作流程）**，由一個個**節點（node）**串接而成。

---

## 認識介面

登入後你會看到這個畫面：

```
┌─────────────────────────────────────────────┐
│  左側選單          主畫面                     │
│  ─────────         ──────────────────────    │
│  Workflows    →    你建立的所有流程列表        │
│  Credentials  →    帳號密碼管理               │
│  Executions   →    每次執行的紀錄             │
└─────────────────────────────────────────────┘
```

最常用的就是 **Workflows**，點進去就可以新增或編輯流程。

---

## 三個最重要的概念

### 1. Workflow（工作流程）
一個完整的自動化任務。例如「每日報表流程」就是一個 workflow。

### 2. Node（節點）
workflow 裡的每一個步驟，就是一個 node。
- **Trigger node（觸發節點）**：決定流程什麼時候啟動，一定是第一個節點
- **Action node（動作節點）**：觸發後要做的每一件事

### 3. Connection（連線）
把節點串起來，資料就會從左邊的節點流向右邊的節點。

```
[定時觸發] ──→ [撈取資料] ──→ [整理格式] ──→ [寄送 Email]
  Trigger          Action         Action          Action
```

## 動手做：建立你的第一個 Workflow

我們來做一個最簡單的流程：**手動觸發 → 顯示一段文字**，目的是熟悉介面操作。

### 第一步｜新增 Workflow

1. 點左側 **Workflows**
2. 點右上角 **+ New workflow**（或 Add workflow）
3. 畫面中央出現一個空白的編輯區域

### 第二步｜加入 Trigger 節點

1. 點畫面中央的 **「+ Add first step」** 或直接點 **「+」**
2. 搜尋框輸入 `manual`
3. 選擇 **Manual Trigger**（手動觸發）
4. 畫面上出現第一個節點

> Manual Trigger 代表「我自己按按鈕來觸發流程」，適合測試用。

### 第三步｜加入 Action 節點

1. 點 Manual Trigger 節點右側的 **「+」** 號
2. 搜尋框輸入 `set`
3. 選擇 **Edit Fields（Set）**
4. 右側設定面板打開

在設定面板裡：
1. 點 **Add field**
2. Name 填：`message`
3. Value 填：`Hello, n8n！我的第一個流程`
4. 關閉面板（點畫面空白處）

### 第四步｜執行看看

1. 點左上角 **「▶ Test workflow」**（或 Execute workflow）
2. 你會看到節點上出現綠色勾勾，代表執行成功
3. 點 Set 節點，右側會顯示輸出資料，你剛才填的 `message` 就在裡面

恭喜，第一個 workflow 完成了！

### 第五步｜儲存

1. 點右上角 **Save**（或 Ctrl + S）
2. 幫 workflow 取個名字，例如「測試流程」
3. 完成

---

## 常用 Trigger（觸發方式）

| Trigger | 說明 | 使用情境 |
|---|---|---|
| Manual Trigger | 手動按按鈕觸發 | 測試、臨時執行 |
| Schedule Trigger | 定時觸發（每天、每小時等） | 每日報表、定期撈資料 |
| Webhook | 收到外部請求時觸發 | 系統通知、表單送出 |

---

## 常用 Action（動作節點）

| Node | 說明 |
|---|---|
| Edit Fields (Set) | 設定或整理資料 |
| HTTP Request | 呼叫外部 API 或網站，也是呼叫自己寫的 Python/Playwright 服務（automation-api）的方式，見[[開發指南 - Python 與 Playwright 實戰]] |
| Send Email | 寄送 Email |
| IF | 條件判斷（如果...就...否則...） |
| Loop Over Items | 對清單裡每一筆資料重複執行 |

---

## 執行紀錄在哪裡看？

左側選單點 **Executions**，可以看到：
- 每次執行的時間
- 成功或失敗
- 每個節點的輸入和輸出資料

失敗時點進去，可以看到哪個節點出錯、錯誤訊息是什麼，方便除錯。

---

## 小提醒

- **Workflow 預設是關閉狀態**，右上角有個開關，要「啟用」後定時觸發才會自動跑
- 測試時用 **Test workflow** 就好，不需要先啟用
- 節點設定隨時可以修改，改完記得按 **Save**
